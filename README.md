## Hyprland Keybinds (Main Modifier: `ALT`)

### 🚀 Apps
* **`ALT + T`** → Open Terminal (`kitty`)
* **`ALT + E`** → Open File Manager (`thunar`)
* **`ALT + P`** → App Launcher (`rofi`)

### 🪟 Windows & Workspaces
* **`ALT + C`** → Close active window
* **`ALT + M`** → Exit Hyprland (Logs you out)
* **`ALT + V`** → Toggle Floating window
* **`ALT + I`** → Toggle Split Direction
* **`ALT + H / J / K / L`** → Move Focus (Vim Style: Left, Down, Up, Right)
* **`ALT + 1-0`** → Switch Workspaces
* **`ALT + Shift + 1-0`** → Move active window to Workspace
* **`ALT + S`** → Toggle Special Scratchpad Workspace
* **`ALT + Shift + S`** → Send window to target Scratchpad
* **`ALT + Mouse Drag`** → Move or Resize windows
* **`ALT + CTRL + H / J / K / L`** → Resize active window (Keyboard)

### 🎛️ Hardware & Media Keys
* **`Volume & Brightness Buttons`** → Dynamically adjust 
* **`Media Buttons`** → Play/Pause/Skip tracks

### 🖥️ Terminal (Kitty) Font Size
* **`CTRL + =`** → Increase Font Size
* **`CTRL + -`** → Decrease Font Size
* **`CTRL + 0`** → Reset Font Size

*To permanently change the default font size, add `font_size 12.0` (or any preferred size) to `kitty/.config/kitty/kitty.conf`.*
